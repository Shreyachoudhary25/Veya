# Veya
A modern women’s wellness platform focused on menstrual health, cycle tracking, hygiene, fitness, and personalized wellness insights.

Veya is a women’s wellness platform designed to help users better understand and manage their menstrual health. It combines cycle tracking, symptom and mood logging, menstrual hygiene guidance, fitness recommendations, and educational wellness resources in one intuitive platform.

Built with the MERN stack, Veya aims to make menstrual health information more accessible while encouraging healthier, more informed lifestyle choices.

Tech Stack: React · Node.js · Express.js · MongoDB · Mongoose · JWT · REST API
